# 记忆功能快速示例

本文档展示如何在实际对话中使用持久化记忆功能。

## 示例对话

### 对话1: 首次使用,记录用户偏好

```
User: 你好,我是一名数据科学家,平时主要使用Python进行数据分析工作,特别喜欢用pandas和matplotlib库。

Agent: 很高兴认识你!我了解到你是一名数据科学家,主要使用Python进行数据分析。
让我帮你记录下这些偏好,以便后续更好地为你服务。

[调用 memory 工具]
memory(
  action="add",
  title="用户职业背景",
  content="用户是一名数据科学家,主要使用Python进行数据分析工作,特别喜欢pandas和matplotlib库",
  category="user_preference",
  priority="high",
  tags=["python", "data-science", "pandas", "matplotlib"]
)

✅ 已成功记录你的偏好!
```

### 对话2: 新会话,Agent自动回忆偏好

```
- 数据总行数: 1000

- 可视化图表: [...]
```

## 最佳实践建议

### 1. 设置合适的优先级

- **high**: 用于长期有效的重要信息(如用户偏好、当前项目)
- **medium**: 用于短期有效的参考信息
- **low**: 用于临时性或不太重要的信息

### 2. 使用清晰的标题和标签

好的标题示例:
- "用户编程语言偏好"
- "当前项目: 智能推荐系统"
- "代码规范要求"

好的标签示例:
- ["python", "preference"]
- ["project", "machine-learning"]
- ["coding-style", "standards"]

### 3. 定期清理过时记忆

```python
# 查看所有记忆
memory(action="list", limit=50)

# 删除不再需要的记忆
memory(action="delete", id="过时记忆的ID")
```

### 4. 合理分类记忆

- `user_preference`: 用户个人偏好
- `important_info`: 重要信息
- `working_context`: 工作上下文
- `general`: 一般信息

## 总结

持久化记忆功能让 Agent 能够:
- ✅ 记住用户偏好,提供个性化服务
- ✅ 保持工作上下文连贯性
- ✅ 减少重复说明相同信息
- ✅ 提升用户体验和效率

合理使用记忆功能,可以让 Agent 更加智能和贴心!
