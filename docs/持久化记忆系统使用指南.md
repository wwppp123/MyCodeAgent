# 持久化记忆系统使用指南

## 概述

持久化记忆系统允许 Agent 跨会话保存和回忆重要信息,包括用户偏好、重要事项、工作上下文等。记忆会自动持久化到本地文件,并在每次会话启动时自动注入到上下文中。

## 核心特性

- ✅ **持久化存储**: 记忆保存在本地 JSON 文件中,重启后仍然保留
- ✅ **优先级管理**: 高优先级记忆自动注入到上下文
- ✅ **分类与标签**: 支持按分类和标签组织记忆
- ✅ **搜索功能**: 快速检索历史记忆
- ✅ **线程安全**: 支持并发访问

## 快速开始

### 1. 基本使用

在对话中,Agent 可以通过 `memory` 工具来管理记忆:

```python
# 添加记忆
memory(
    action="add",
    title="用户偏好",
    content="我喜欢使用Python进行数据分析,偏好使用VS Code编辑器",
    category="user_preference",
    priority="high",
    tags=["preference", "python"]
)

# 搜索记忆
memory(action="search", query="Python")

# 列出所有记忆
memory(action="list", limit=10)

# 获取统计信息
memory(action="stats")
```

### 2. 记忆分类

支持以下预定义分类:

- `user_preference`: 用户偏好设置(如编程语言偏好、工具偏好等)
- `important_info`: 重要信息(如账号信息、关键配置等)
- `working_context`: 工作上下文(如当前项目、开发任务等)
- `general`: 一般信息(默认分类)

### 3. 优先级说明

支持三个优先级:

- **high**: 高优先级记忆会自动注入到每次对话的上下文中(最多显示前100条)
- **medium**: 中优先级记忆,不会自动注入,但可以通过搜索访问
- **low**: 低优先级记忆,用于存储临时或不太重要的信息

## 工具接口详解

### memory_add - 添加记忆

```json
{
  "action": "add",
  "title": "记忆标题",
  "content": "记忆内容",
  "category": "user_preference",
  "priority": "high",
  "tags": ["tag1", "tag2"]
}
```

**参数说明**:
- `title` (必需): 记忆标题,简短描述
- `content` (必需): 记忆内容,详细描述
- `category` (可选): 分类,默认为 `general`
- `priority` (可选): 优先级,默认为 `medium`
- `tags` (可选): 标签列表,用于分类和检索

### memory_update - 更新记忆

```json
{
  "action": "update",
  "id": "memory_id",
  "title": "新标题",
  "content": "新内容",
  "priority": "high"
}
```

**参数说明**:
- `id` (必需): 要更新的记忆ID
- 其他参数均为可选,只更新指定的字段

### memory_delete - 删除记忆

```json
{
  "action": "delete",
  "id": "memory_id"
}
```

### memory_list - 列出记忆

```json
{
  "action": "list",
  "category": "user_preference",
  "priority": "high",
  "tags": ["python"],
  "limit": 10
}
```

**参数说明**:
- `category` (可选): 按分类过滤
- `priority` (可选): 按优先级过滤
- `tags` (可选): 按标签过滤(记忆需包含所有指定标签)
- `limit` (可选): 返回数量限制,默认10,最大100

### memory_search - 搜索记忆

```json
{
  "action": "search",
  "query": "Python",
  "limit": 20
}
```

**参数说明**:
- `query` (必需): 搜索关键词(在标题和内容中搜索)
- `limit` (可选): 返回数量限制,默认20

### memory_get - 获取单个记忆

```json
{
  "action": "get",
  "id": "memory_id"
}
```

### memory_stats - 获取统计信息

```json
{
  "action": "stats"
}
```

返回记忆总数、分类统计和优先级统计。

## 配置选项

通过环境变量配置记忆系统:

```bash
# 记忆存储路径(默认: .agent_memory/memory.json)
export MEMORY_STORE_PATH=".agent_memory/memory.json"
```

## 最佳实践

### 1. 合理设置优先级

- 将**长期有效、重要**的信息设置为 `high` 优先级
- 将**短期有效、参考性**的信息设置为 `medium` 优先级
- 将**临时性、不重要**的信息设置为 `low` 优先级

### 2. 使用有意义的标题和标签

```python
# 好的做法
title="Python数据分析偏好"
tags=["python", "data-analysis", "preference"]

# 不好的做法
title="偏好"
tags=["tag1", "tag2"]
```

### 3. 定期清理过时记忆

```python
# 查看所有记忆
memory(action="list", limit=50)

# 删除过时的记忆
memory(action="delete", id="old_memory_id")
```

### 4. 分类管理

使用合适的分类帮助组织记忆:

- **用户偏好** → `user_preference`
- **重要信息** → `important_info`
- **项目相关** → `working_context`
- **其他信息** → `general`

## 存储结构

记忆存储在 JSON 文件中,结构如下:

```json
{
  "version": 1,
  "updated_at": "2025-03-31T12:00:00",
  "memories": {
    "memory_id_1": {
      "id": "memory_id_1",
      "title": "记忆标题",
      "content": "记忆内容",
      "category": "user_preference",
      "priority": "high",
      "tags": ["tag1", "tag2"],
      "created_at": "2025-03-31T10:00:00",
      "updated_at": "2025-03-31T12:00:00"
    }
  }
}
```

## 注意事项

1. **隐私安全**: 记忆文件是明文存储,不要保存敏感信息(如密码、API密钥等)
2. **存储空间**: 高优先级记忆会注入上下文,注意控制总数避免占用过多token
3. **并发访问**: 系统使用锁机制保证线程安全,但建议避免频繁并发写入
4. **文件备份**: 建议定期备份记忆文件 `.agent_memory/memory.json`

## 故障排查

### 问题1: 记忆没有自动注入上下文

**解决方案**:
- 检查记忆优先级是否为 `high`
- 检查记忆文件是否存在且格式正确
- 查看日志确认 MemoryStore 是否正常初始化

### 问题2: 记忆文件损坏

**解决方案**:
- 从备份恢复记忆文件
- 或删除损坏文件,系统会自动创建新的空文件

### 问题3: 记忆搜索不到

**解决方案**:
- 检查搜索关键词是否正确
- 使用 `memory(action="list")` 查看所有记忆
- 检查记忆是否被意外删除

## 总结

持久化记忆系统让 Agent 具备了"长期记忆"能力,能够跨会话记住重要信息,提供更加个性化和连贯的服务。合理使用记忆系统可以大大提升 Agent 的智能化水平和用户体验。
