# 记忆数据管理说明

## 问题说明

用户发现记忆文件 `.agent_memory/memory.json` 中有不是自己信息的记忆数据。

## 原因分析

记忆文件中包含了**演示脚本创建的示例数据**：

```json
{
  "用户身份信息": "张三, Python开发工程师",  // ❌ 示例数据
  "开发工具偏好": "VS Code编辑器",           // ❌ 示例数据
  "当前项目": "机器学习项目",                // ❌ 示例数据
  "用户身份信息": "王鹏"                     // ✅ 真实数据
}
```

前三条是运行 `scripts/demo_memory_usage.py` 演示脚本时创建的。

## 解决方案

### 1. 清理示例数据

运行清理脚本：

```bash
python scripts/clean_demo_memories.py
```

清理结果：
```
删除了 3 条示例数据
保留了 1 条真实数据
```

### 2. 验证清理结果

查看记忆文件：

```bash
cat .agent_memory/memory.json
```

应该只包含你的真实信息。

## 预防措施

### 方法 1: 演示脚本使用临时目录（推荐）

修改演示脚本，使用临时目录而不是真实记忆文件：

```python
import tempfile

def demo_memory_usage():
    # 使用临时目录
    with tempfile.TemporaryDirectory() as tmpdir:
        memory_file = Path(tmpdir) / "memory.json"
        store = MemoryStore(store_path=str(memory_file))

        # 演示代码...
        # 退出时自动清理
```

**优点**：
- ✅ 不会污染真实记忆文件
- ✅ 自动清理临时数据
- ✅ 安全可靠

### 方法 2: 添加清理说明

在演示脚本中添加明确的清理说明：

```python
"""
演示持久化记忆功能的使用

⚠️ 注意: 此脚本会创建示例数据到真实的记忆文件中！
建议: 使用后运行清理脚本删除示例数据
清理命令: python scripts/clean_demo_memories.py
"""
```

### 方法 3: 使用标记区分

在示例数据中添加特殊标记：

```python
memory = store.add(
    title="[DEMO] 用户身份信息",  # 添加 [DEMO] 前缀
    content="示例数据: 张三",
    tags=["demo", "test"],  # 添加 demo 标签
    priority="low"  # 使用低优先级
)
```

清理时可以精确识别：

```python
# 删除所有标记为 demo 的记忆
for memory in store.list():
    if "demo" in memory.tags or memory.title.startswith("[DEMO]"):
        store.delete(memory.id)
```

## 常见问题

### Q1: 如何查看当前所有记忆？

```bash
cat .agent_memory/memory.json
```

或使用统计：
```python
from core.memory_store import MemoryStore
store = MemoryStore()
print(store.stats())
```

### Q2: 如何删除特定记忆？

```python
from core.memory_store import MemoryStore

store = MemoryStore()

# 搜索要删除的记忆
memories = store.search("关键词")

# 删除
for memory in memories:
    store.delete(memory.id)
```

### Q3: 如何清空所有记忆？

⚠️ 谨慎操作！

```python
from core.memory_store import MemoryStore
store = MemoryStore()
store.clear()  # 清空所有记忆
```

### Q4: 记忆会占用多少空间？

每条记忆大约 200-500 字节，100 条记忆约 20-50KB，非常小。
